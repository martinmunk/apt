martinmunk apt repository

Debian packages built by GitHub Actions from the repositories at github.com/martinmunk. Suite trixie, component main, architectures amd64, arm64, armhf (plus all).

Use it

curl -fsSL https://martinmunk.github.io/apt/martinmunk-apt.gpg | sudo tee /usr/share/keyrings/martinmunk-apt.gpg >/dev/null
echo "deb [signed-by=/usr/share/keyrings/martinmunk-apt.gpg] https://martinmunk.github.io/apt trixie main" | sudo tee /etc/apt/sources.list.d/martinmunk.list
sudo apt update

The signing key is also available ASCII-armored as martinmunk-apt.asc. The current package list is in packages.txt; the sources are github.com/martinmunk/apt.
